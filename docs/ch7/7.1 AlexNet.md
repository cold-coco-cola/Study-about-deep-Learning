# **7.1. 深度卷积神经网络(AlexNet)**

## 7.1.1 深度？

目前通读一遍下来，感觉是LeNet的加深加强版。但其出现有着特殊意义。是个很有意思的故事：

在传统CV领域机器学习应用中，需要人为设计特征识别算法，然后将识别出来的特征转化为向量，再让机器进行学习分类。
   
   
 - e.g人为设计圆形特征、水平线特征识别算法，然后机器根据获得的特征进行学习，学习到“这样的特征大概率是一辆车”。

这样的模式可解释性强，算力需求低，数据依赖性弱。但是依赖于人类发现特征。例如，如果设计特征时没有想到轮胎这一个特征，可能会把滚筒洗衣机也搞成汽车；或者设计了后视镜识别器，但由于意外这个汽车的后视镜被撞坏了，或者像现在各种长相新奇的新能源汽车后视镜一样，机器就抓不到这一特征了。

[*设计一套新的特征函数、改进结果，并撰写论文是盛极一时的潮流。*](https://zh-v2.d2l.ai/chapter_convolutional-modern/alexnet.html)

但Yann LeCun、Geoff Hinton、Yoshua Bengio、Andrew Ng等研究人员认为特征本身应该被学习。特征应该由多个共同学习的神经网络层组成，每个层都有可学习的参数。在机器视觉中，最底层可能检测边缘、颜色和纹理。随着***数据(ImageNet)、硬件***两个关键因素的发展，Alex Krizhevsky、Ilya Sutskever和Geoff Hinton提出了一种新的卷积神经网络变体AlexNet。该变体在2012ImageNet中夺魁。并且，网络的最底层学习到了类似滤波器的特征抽取器：

![AlexNet第一层学习到的特征抽取器。](https://zh-v2.d2l.ai/_images/filters.png)

这证明了，机器能够自学特征，而且完爆人类设计的特征。于是CV研究从“写出精妙特征特征算法”转向了网络设计。


## 7.1.2 AlexNet

架构示意图：

![alt text](https://zh-v2.d2l.ai/_images/alexnet.svg)

> 比AlexNet更深；使用ReLu作为激活函数；由于图像大小，卷积通道更多（10倍于LeNet）、卷积窗口更大（$11 \times 11$）。

*当sigmoid激活函数的输出非常接近于0或1时，这些区域的梯度几乎为0，因此反向传播无法继续更新一些模型参数。*

代码实现：


```python
import os
# 如果在运行训练板块时遇到内核崩溃，可以取消下面两行代码的注释来解决
# os.environ['KMP_DUPLICATE_LIB_OK'] = 'TRUE'
# os.environ['OMP_NUM_THREADS'] = '1'

import torch
from torch import nn
from d2l import torch as d2l

net = nn.Sequential(
    # 这里使用一个11*11的更大窗口来捕捉对象。
    # 同时，步幅为4，以减少输出的高度和宽度。
    # 另外，输出通道的数目远大于LeNet
    nn.Conv2d(1, 96, kernel_size=11, stride=4, padding=1), nn.ReLU(),
    nn.MaxPool2d(kernel_size=3, stride=2),
    # 减小卷积窗口，使用填充为2来使得输入与输出的高和宽一致，且增大输出通道数
    nn.Conv2d(96, 256, kernel_size=5, padding=2), nn.ReLU(),
    nn.MaxPool2d(kernel_size=3, stride=2),
    # 使用三个连续的卷积层和较小的卷积窗口。
    # 除了最后的卷积层，输出通道的数量进一步增加。
    # 在前两个卷积层之后，汇聚层不用于减少输入的高度和宽度
    nn.Conv2d(256, 384, kernel_size=3, padding=1), nn.ReLU(),
    nn.Conv2d(384, 384, kernel_size=3, padding=1), nn.ReLU(),
    nn.Conv2d(384, 256, kernel_size=3, padding=1), nn.ReLU(),
    nn.MaxPool2d(kernel_size=3, stride=2),
    nn.Flatten(),
    # 这里，全连接层的输出数量是LeNet中的好几倍。使用dropout层来减轻过拟合
    nn.Linear(6400, 4096), nn.ReLU(),
    nn.Dropout(p=0.5),
    nn.Linear(4096, 4096), nn.ReLU(),
    nn.Dropout(p=0.5),
    # 最后是输出层。由于这里使用Fashion-MNIST，所以用类别数为10，而非论文中的1000
    nn.Linear(4096, 10))
```

回答[d2l-ai-solutions-manual](https://github.com/datawhalechina/d2l-ai-solutions-manual/blob/master/docs/ch07/ch07.md)展示了迭代次数从10轮到30轮时LeNet和AlexNet的效果对比：

以下是分别使用AlexNet模型和LeNet模型，在epoch为10，20，30情况下，train_acc和test_acc的精度。

|model|epochs|train_acc|test_acc|
|:-:|:-:|:-:|:-:|
|AlexNet|10|0.879|0.875|
|AlexNet|20|0.907|0.900|  
|AlexNet|30|0.924|0.912|
|LeNet|10|0.857|0.856|
|LeNet|20|0.889|0.876|  
|LeNet|30|0.905|0.890|

1. AlexNet整体上比LeNet有更高的训练和测试准确率,这说明AlexNet模型更加高效,有更强的拟合能力。

2. 随着epoch的增加,两种模型的训练准确率和测试准确率均有不同程度的提高,但AlexNet的提高速度更快,这再次说明AlexNet模型更强大。

3. AlexNet的训练准确率和测试准确率的差距较小,这说明AlexNet有更好的泛化能力,较少过拟合。而LeNet的差距较大,过拟合现象更严重。

4. AlexNet在30个epoch后,训练准确率继续提高but测试准确率趋于稳定,这表现出一定的过拟合。而LeNet两者的差距仍在扩大,过拟合更加严重。

综上,AlexNet大约在20-30个epoch之间达到最佳效果,LeNet可能需要提前停止,在20个epoch左右。
