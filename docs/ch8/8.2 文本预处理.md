# 8.2 **文本预处理**

*该篇文字部分主要为d2l原文，整体对原书进行了简化。笔记中主要是加了些代码注释*

将文本视作一串单词序列数据。数据自然需要预处理。如下是常见步骤：

1. 将文本作为字符串加载到内存中。

2. 将字符串拆分为词元（如单词和字符）。

3. 建立一个词表，将拆分的词元映射到数字索引。

4. 将文本转换为数字索引序列，方便模型操作。


## 8.2.1  读取数据集

H.G.Well的[时光机器](https://www.gutenberg.org/ebooks/35)是一个相当小的语料库，只有30000多个单词。而现实中的文档集合可能会包含数十亿个单词。


```python
import collections
import re
from d2l import torch as d2l

#@save
d2l.DATA_HUB['time_machine'] = (d2l.DATA_URL + 'timemachine.txt',
                                '090b5e7e70c295757f55df93cb0a180b9691891a')

def read_time_machine():  #@save
    """将时间机器数据集加载到文本行的列表中"""
    with open(d2l.download('time_machine'), 'r') as f:
        lines = f.readlines()
    return [re.sub('[^A-Za-z]+', ' ', line).strip().lower() for line in lines]

lines = read_time_machine()
print(f'# 文本总行数: {len(lines)}')
print(lines[0])
print(lines[10])
```

## 8.2.2 词元化
数据集中，是输入列表的每一个元素是每一行文本。“词元化”顾名思义，将其细拆开来。


```python
def tokenize(lines, token='word'):  #@save
    """将文本行拆分为单词或字符"""
    if token == 'word':
        return [line.split() for line in lines]
    
    # == 'char'表示将文本行拆分为字符,例如 "love" 会变成 ["l", "o", "v", "e"]
    elif token == 'char': 
        return [list(line) for line in lines]
    

    else:
        print('错误：未知词元类型:' + token)

tokens = tokenize(lines)
for i in range(11):
    print(tokens[i])
```

## 8.2.3 词表

显然，将字符串类型映射为数字会更利于后续的计算。我们尝试构建一个字典，把词元给映射到数字索引当中，这也叫做词表。下面的操作采用d2l中的原话：

*[先将训练集中的所有文档合并在一起，对它们的唯一词元进行统计， 得到的统计结果称之为语料（corpus）。 然后根据每个唯一词元的出现频率，为其分配一个数字索引。 很少出现的词元通常被移除，这可以降低复杂性。 另外，语料库中不存在或已删除的任何词元都将映射到一个特定的未知词元“ \<unk\>”。 我们可以选择增加一个列表，用于保存那些被保留的词元， 例如：填充词元（“ \<pad\> ”）； 序列开始词元（“\<bos\>”）； 序列结束词元（“\<eos\>”）](https://zh-v2.d2l.ai/chapter_recurrent-neural-networks/text-preprocessing.html)*


```python
class Vocab:  #@save
    """文本词表"""
    def __init__(self, tokens=None, min_freq=0, reserved_tokens=None):
        if tokens is None:
            tokens = []
        if reserved_tokens is None:
            reserved_tokens = []
        # 按出现频率排序
        counter = count_corpus(tokens) # 统计词频
        self._token_freqs = sorted(counter.items(), key=lambda x: x[1],
                                   reverse=True)
        # 未知词元的索引为0
        self.idx_to_token = ['<unk>'] + reserved_tokens #idx_to_token是一个列表,其中包含了词表中的所有词元,并且按照索引顺序排列
        self.token_to_idx = {token: idx                 #token_to_idx是一个字典,其中包含了词表中的所有词元及其对应的索引,通过idx_to_token列表和enumerate函数来创建这个字典
                             for idx, token in enumerate(self.idx_to_token)} #enumerate is useful for obtaining an indexed list:(0, seq[0]), (1, seq[1]), (2, seq[2]), ...
        for token, freq in self._token_freqs:
            if freq < min_freq:
                break
            if token not in self.token_to_idx:
                self.idx_to_token.append(token)
                self.token_to_idx[token] = len(self.idx_to_token) - 1

    def __len__(self):
        return len(self.idx_to_token)

    def __getitem__(self, tokens):
        if not isinstance(tokens, (list, tuple)):
            return self.token_to_idx.get(tokens, self.unk) #如果tokens不是列表或元组（即就是token）,则直接返回该token的索引,如果该token不在词表中,则返回未知词元的索引
        return [self.__getitem__(token) for token in tokens] #如果tokens是列表或元组,则递归调用__getitem__方法来获取每个token的索引,并返回一个包含这些索引的列表

    def to_tokens(self, indices):
        if not isinstance(indices, (list, tuple)):
            return self.idx_to_token[indices]              #如果indices不是列表或元组（即就是index）,则直接返回该index的词元。
        return [self.idx_to_token[index] for index in indices] #如果indices是列表或元组,则递归调用to_tokens方法来获取每个index的词元,并返回一个包含这些词元的列表

    @property
    def unk(self):  # 未知词元的索引为0
        return 0

    @property
    def token_freqs(self):
        return self._token_freqs

def count_corpus(tokens):  #@save
    """统计词元的频率"""
    # 这里的tokens是1D列表或2D列表
    if len(tokens) == 0 or isinstance(tokens[0], list):
        # 将词元列表展平成一个列表
        tokens = [token for line in tokens for token in line]
    return collections.Counter(tokens)
```

## 8.2.4 整合功能

在使用上述函数时，我们将所有功能打包到load_corpus_time_machine函数中， 该函数返回corpus（词元索引列表）和vocab（时光机器语料库的词表）。 

1. 为了简化后面章节中的训练，我们使用字符（而不是单词）实现文本词元化；

2. 时光机器数据集中的每个文本行不一定是一个句子或一个段落，还可能是一个单词，因此返回的corpus仅处理为单个列表，而不是使用多词元列表构成的一个列表。


```python
def load_corpus_time_machine(max_tokens=-1):  #@save
    """返回时光机器数据集的词元索引列表和词表"""
    lines = read_time_machine()
    tokens = tokenize(lines, 'char')
    vocab = Vocab(tokens)
    # 因为时光机器数据集中的每个文本行不一定是一个句子或一个段落，
    # 所以将所有文本行展平到一个列表中
    corpus = [vocab[token] for line in tokens for token in line]
    if max_tokens > 0:
        corpus = corpus[:max_tokens]
    return corpus, vocab

corpus, vocab = load_corpus_time_machine()
```
